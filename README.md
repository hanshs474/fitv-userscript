# fitv-userscript

Free image to video AI with no daily cap: start with no sign-up, keep going on a free account. Every video comes with sound and no watermark. This userscript lets you turn selected text on any web page into an AI video clip with [Free Image to Video](https://freeimagetovideo.ai/?utm_source=greasyfork&utm_medium=userscript).

Create an API key at [freeimagetovideo.ai/settings/apikeys](https://freeimagetovideo.ai/settings/apikeys) ([pricing](https://freeimagetovideo.ai/pricing)).

On the web: [image to video AI with sound](https://freeimagetovideo.ai/video/image-to-video-ai-with-sound) and [free text to video AI](https://freeimagetovideo.ai/video/free-text-to-video-ai).
